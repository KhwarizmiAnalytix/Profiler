# Sample outputs

Generated by `example_reports`, `example_hta`, and `analyze_hta.py` on macOS
(Apple Silicon), using a Release Kineto CPU build and HolisticTraceAnalysis 0.5.0
with Python 3.13. The HTA trace has been pretty-printed and its machine hostname
removed. Event durations and IDs are unchanged. These captures demonstrate the
formats; they are not performance benchmarks or GPU measurements.

- `native/`: all six files from `example_reports`.
- `hta/rank0.json`: the Kineto trace from `example_hta`.
- `hta/rank0_cpu.csv`: the Python script's inclusive CPU aggregation.

Try the checked-in trace without building C++:

```bash
python examples/analyze_hta.py docs/samples/hta --output build/sample-hta-results
```

Install `examples/requirements-hta.txt` first. See [output explanations](../outputs.md)
and [the HTA workflow](../hta.md) for regeneration commands and field meanings.
